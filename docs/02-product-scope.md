# 产品定位与范围

> 本文是方案建议，不是已实现能力，也不是经警方验证的需求。2026-10-08 建立。

## 1. 一句话定位

**面向经授权的刑事调查人员，把合法获得的卷宗与结构化材料转成可核查、可纠错、可审计的调查工作台。**

不承诺“AI 自动破案”。核心交付是：材料整理、带原文引用的问答、多人陈述时间线对齐、待核查冲突、证据关联展示、可人工修改的报告草稿。

### 保存的用户原话

> 有一个灵感你帮我记录一下，做一个侦破案件 AI agent

> 你继续记录这个 AI agent 面对的是专业的刑事警察，在面对真实的刑事案件时使用。

以上是产品方向；以下均为研究后的建议，不冒充用户原话。原始灵感文件保持不变。

## 2. 谁使用，谁购买

- 日常使用者：办案人员、案件研判人员、审核人员；权限与职责不能混成一个“管理员”。
- 采购/交付参与者：业务部门、信息化部门、采购部门、网络与保密管理人员、现有系统集成商。
- 真正的痛点需要访谈验证：不能凭研究新闻宣称刑警一定愿意使用，也不能把法院/检察院阅卷需求直接等同刑侦需求。
- 推荐商业形态：经授权内网部署的单案件工作台/现有办案系统中的插件，而不是消费级云端聊天订阅。

## 3. MVP：只解决一个窄而真实的工作流

首个假设：**多份笔录及配套文本材料的时间线整理与冲突复核**。

```text
选择案件 → 导入材料 → OCR/解析及人工校对 → 按来源抽取陈述
        → 时间线和事件并排对照 → 提示待核查差异 → 点开原页
        → 人工确认/驳回/改写 → 导出带引用的草稿
```

### P0 必做

| 功能 | 输入/输出 | 验收边界 |
|---|---|---|
| 案件与材料目录 | PDF、图片、文本；逐页定位 | 原件只读，解析结果单独版本化 |
| 原页证据定位 | 原文摘录 + 文档/页码/框选位置 | 点引用能够回到同一版本的原页 |
| 限定案件问答 | 只检索当前用户可见的材料 | 没有材料支持就明确“不足以回答” |
| 陈述时间线 | 发言人、陈述时间、事件时间/范围、原文 | 模糊时间保留模糊，不硬补日期 |
| 差异复核 | 两段以上原文并排 + 冲突类型 | “陈述不一致/待核查”不等于撒谎或犯罪 |
| 人工审核 | 确认、驳回、修改及理由 | 保留 AI 初稿、人改稿、审核人和版本 |
| 权限与导出审计 | 案件 ACL、任务状态、草稿 PDF/Word | 未审核内容显式标注；禁止自动写回正式案件系统 |

### P1：P0 达标以后

- 有来源的实体/关系图：节点和每条边均能返回原文；支持同名拆分、别名合并的人工确认。
- 证据覆盖与材料缺口：只基于当前授权材料，说明覆盖范围，不宣称“已读全案”或给嫌疑人概率。
- 结构化导入：合法提供的取证报告、CSV、表格导出；对接既有取证工具，而非自行绕过设备安全。
- 版本比较、批量异步任务、审核队列、同案件多人协作。

### P2：需要明确授权及业务验证

- 跨案件检索/串并案辅助：先做授权、访问理由、审批、可撤销的索引范围；不默认把全库变成所有人可搜。
- 多模态音视频：原视频/音频定位、转写复核、时钟校准；不把声音/外貌推断当证据。
- 集成正式业务系统：只走批准接口；写入、导出、外发必须审批。

## 4. 不做什么

1. 不判断有罪、不自动锁定“凶手”、不给人生成犯罪风险分。
2. 不根据民族、宗教、政治观点等敏感属性给人物画像或侦查排序。
3. 不做大规模公共摄像追踪、未授权身份识别、破解设备或绕过权限。
4. 不替代取证合法性、证据真实性、证据能力及证明力的专业判断。
5. 不把合成演示案例当真实案件，不上传真实卷宗到 GitHub（包括私有仓库）。
6. 不开放公网搜人、随意联网、通用 shell、任意 SQL 等 Agent 工具。

## 5. UI：不是一个聊天框

建议桌面工作台三栏：**左侧材料目录/案件状态，中间原件查看器，右侧时间线/差异/问答和审核**。引用点击后在原页高亮；每条事件显示“某人陈述/记录载明/人工确认”等状态。

- 不用红绿颜色作为唯一状态；同时使用文字、图标、边框，适配色弱。
- 键盘可打开引用、切换证据、提交审核；焦点清晰可见。
- 疑点不使用煽动性红色“犯罪标签”，而是中性的“时间差异”“主体待确认”。
- 默认先显示原文与来源，再显示 AI 提议；把反证放在同屏，而非藏到下一轮聊天。
- 长任务显示进度、正在处理的材料范围和失败项；失败项不能被摘要悄悄忽略。
- 不加载外部字体、CDN、在线统计；内网资源全部随包提供。

## 6. 是否值得做

**作为个人技术项目：值得做一个可评测的窄原型。作为立即创业卖给公安的整套平台：不建议直接冲。**

核心假设不是“有没有人会买 AI”，而是“人员复核同一组材料能否更快、遗漏更少，且不增加误导”。如果拿不到合规数据、业务访谈和交付合作方，先停留在合成数据原型；不要靠新闻报道推导收入。

可能的进入路径：合成材料演示 → 有授权的专业访谈 → 与有行业交付能力的集成商联合验证 → 合规试点 → 项目验收。每一步都可能止步；顺序不能用漂亮的 demo 代替。
