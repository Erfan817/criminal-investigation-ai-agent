# 安全、合规与真实数据准入

> 2026-10-08公开资料核对后的方案边界；不是律师意见、保密审批或项目放行。完整条文/版本核对见[合规研究](../research/compliance-notes.md)及[来源台账](../research/compliance-sources.json)。

## 1. 先纠正几个容易想当然的判断

- 不是所有案件卷宗自动属于国家秘密；定密由有权单位按规定做。非涉密也不等于可以上传公网/私人开发机。
- 不是所有政府/公安AI系统一律等保三级；定级依系统重要性和受损危害，按项目确认。
- 不是所有软件商一律需同一种涉密资质；承接法定列举的涉密集成等业务才触发对应要求。
- 不是政府绝对禁云：批准的境内云/政务云与公网消费级SaaS不同，须核对材料级别、网络域、服务链路、运维与审批。
- 不是买了国产模型或做了私有部署就已合规；合法处理依据、授权、委托、评估、审计和人员责任仍需满足。
- GitHub私有仓库仍不是可存真实卷宗的生产环境；原件、OCR、embedding、案情prompt、日志、截图、备份均不入库。

## 2. 要求分为三层

| 类别 | 示例 | 谁确认 |
|---|---|---|
| 法定义务 | 国家机关个人信息境内存储、权限程序与必要范围；敏感信息/委托等事前影响评估；政务数据委托严格批准；依法定密/涉密系统保护 | 使用单位法务、个人信息/数据、安全与保密负责人 |
| 项目条件 | 招标资格、接入网络域、SSO、信创/密码适配、测评、驻场、SLA、日志保留、验收 | 业务/采购/信息化等项目责任人 |
| 工程建议 | 只读原件、断言级引用、案件ACL、默认不外连、受控工具、人审、回滚、反证并列 | 技术团队实现并供项目验收 |

建议可以在合同中变成义务，但不能反过来冒称全国通用法律。

## 3. 中国法规中与设计直接相关的点

- 《个人信息保护法》13、33—36条：国家机关为履行法定职责处理个人信息仍受权限、程序、必要范围限制；境内存储，确需出境须安全评估。
- 21/59及55—56条：委托范围、监督、转委托、终止返还/删除；敏感信息、委托等事前影响评估，报告及处理记录至少三年。
- 《数据安全法》38—40条及《网络数据安全管理条例》相关条款：政务系统建设/维护等委托处理须严格批准，供应商不得超范围访问/留存/复用；训练、跨客户利用不默认获准。
- 《保守国家秘密法》及实施条例：依法定密，涉密系统检查和资质按业务触发；普通断网电脑不等于涉密合规环境。
- 2026现行《网络安全法》**23条**为等保义务及相关网络日志不少于六个月，不能继续引用旧版21条作现行条号。网络运行日志、业务审计、个人信息处理记录并非同一种日志，保留规则分别核对。
- 《生成式人工智能服务管理暂行办法》2条有向境内公众提供服务的适用范围；内部研发/应用不当然适用该办法，但其他法律与单位制度仍适用。
- 政府采购法允许法人、其他组织、自然人为供应商，不等于个人即可承接所有具体项目；资格、能力、保密与采购方式逐项目判断。

不索要真实案件资料来“先试试”，免费PoC也不绕过审批。

## 4. 证据保全与AI输出

原件与派生材料分开。哈希只能帮助校验版本完整性，不证明来源合法、陈述真实或人物身份。导入来源、取得过程、封存/移交、处理版本、人工校对和审核不能被一个哈希代替。

AI摘要/时间线定位为**辅助草稿**，不自动变成证据或鉴定意见；具体材料的证据资格须依类别、来源、真实性、合法性和关联性专业审查。不作“所有AI文件永远不可能有证据价值”的绝对法理判断。

不输出嫌疑人有罪概率、证人可信度、证据真实性/证明力分数，不自动触发强制措施。

## 5. 上线前六道门

1. **数据门**：合法来源、用途、范围、定密/分级、委托与转委托、训练禁止/许可明确。
2. **环境门**：批准网络域、模型/OCR/向量服务、所有数据链路和运维；适用定级/保密/密码要求已确认。
3. **权限门**：案件授权在检索前执行，缓存/原页/任务/导出一起检查；撤权立即生效。
4. **质量门**：精标任务测试、引用/遗漏/差异误报、反证、拒答和失败范围说明。
5. **人审门**：有权限/信息/时间的人员能核对、修改、驳回，修改后重审；保留版本。
6. **交付门**：离线包、依赖/权重许可、SBOM、审计、备份恢复、应急停止、迁移/返还/删除及采购验收。

任何一道未过，只允许合成数据原型，不准接真实案件。点击“我同意”不能替代上述门槛。

## 6. 国外规则作为风险设计对照

欧盟AI Act与美国联邦OMB材料提醒：高风险取决于真实用途及对决定的影响，“辅助”“有人审”不是自动免责。自动评估证据可靠性、画像或犯罪风险与普通资料编目/检索不是同一风险层级。

版本核对：本次欧委会现行113条和AI Omnibus生效公告显示附录III高风险规则适用日延至2027-12-02，附录I相关规则为2028-08-02；既有禁止用途的原适用日仍须分别看条文。美国采用M-25-21/M-25-22而非已被替代的2024版本。详见合规研究，不把国外政策变成中国统一资质。

**仍不能从公开研究得出的结论**：具体公安保密范围、定级、关基身份、云许可、密码/信创要求、内部接入规范和本项目供应商资格；须使用单位逐项确认。
