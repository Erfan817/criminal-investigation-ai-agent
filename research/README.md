# 研究方法、来源与局限

**基准：2026-10-08。** 这是一轮中文/英文、国内/国外公开网络研究，不是“互联网所有信息已搜完”，也不是产品测评、客户访谈或法律合规放行。

## 覆盖

- 国内：公共安全/刑事材料与笔录工具、公安自研案例、检察相邻产品、取证装备，另查政府采购链与易混淆候选。
- 国外：以色列、加拿大、美国、爱尔兰、英国/德国及波兰相关调查/取证/图谱平台、具名客户与政府材料。
- 合规：政府/主管机关公布的中国法律法规、欧委会条文服务/生效公告、美国联邦OMB文件。
- 工程：官方OCR/检索/模型/框架/许可资料，以及英国政府AI指南、NIST和OWASP。

## 如何避免宣传稿变成事实

分别记录：

1. 产品/技术文档：公开描述了什么，不等于效果实测。
2. 厂商匿名案例：弱落地线索，不当具名公安使用证明。
3. 厂商具名客户：比匿名强，不是客户独立发布/合同。
4. 客户/政府公开说明：可证明自身描述的部署/使用，未必是原始采购或验收。
5. 招标：需求与计划；中标：选定供应商；签约：合同成立；正式部署/验收：另需证据。
6. 入围/采购框架/marketplace/Awardable：可购买通道/资格，不等于订单或收入。

产品模块与阶段分别确认：同厂商旧取证产品买过，不证明新Agent采购；其他SKU本地部署，不证明新生成式模块离线；early access、试点、GA和正式验收不是一回事。

## 日期与费用

网页初发、修改、会议、签约、可用时间与法规生效/适用日期分开；URL目录/版权年不能自动作为发布日期。冲突/模糊日期保留未知，不猜。

本研究没有取得通用软件价格或统一性能指标。广州合同金额和英国续约价只对应各自项目，不换算为单席位价、GPU预算或创业收入。

## 留档与隐私

仓库仅保留相关短摘录、真实URL、访问状态与判断。完整抓取/原文校验材料在本地`research-work/`（被`.gitignore`排除），不推送全文、公开新闻中的真实案情、采购银行信息或真实刑事个人资料。

本地留档帮助核对，不把网页全文的版权转授给本仓库。来源可变/失效；必要时用项目编号、公告ID、正式产品名回到官方门户。
