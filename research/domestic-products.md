# 中国境内刑事调查 / 卷宗分析 AI 同类产品研究

检索日期：2026-10-08（由父任务工具核实）。本报告只覆盖本轮实际检索并读取到的公开资料，不声称是截至该日的完整市场清单。

## 结论先行

1. **这不是空白市场。** 国内已有卷宗结构化、证据规则校验、笔录矛盾提示、案件知识图谱、跨系统智能助手等产品。卷宗摘要、关系图、矛盾提示本身不足以成为差异化。
2. **最值得对标的直接案例是上海“206”和昆山 AI 智能笔录辅助系统。** 前者有政府政法网站刊载的客户采访及公安应用报道；后者有苏州政府报道与署名昆山公安的技术案例。二者都不是“自主侦破并给出罪犯”的证据。“206”是早期规则 / NLP / 语音协同体系，不能因名称里有 AI 就改称 LLM Agent。
3. **找到一笔可以从一手来源核验的公安大模型采购链：广州 CZ2026-0252。** 2026-05-15招标、2026-06-12中标、2026-07-22合同公告均已从广东官方采购门户读取正文。供应商是中国电信股份有限公司广东分公司，合同金额人民币1,864,631.00元。它证明真实采购及签约，**不证明已部署、已验收，也不证明采购了卷宗矛盾识别功能**；详细需求附件未读到。
4. **主表收录8个有具体公开名称的产品 / 系统：6个直接相关，2个相邻工具。** 不把8个都说成已验收的刑侦 Agent。海致、海鑫、华为另列候选核查结果，避免把图数据库、指纹比对、城市生命线监测凑成卷宗竞品。
5. 对私有项目更合理的定位是：**案件材料整理与核对工作台**。价值围绕出处可回溯、人工确认、时间与实体核对、争议保留、审计与接入既有流程；不是自动事实认定、推断谁有罪、量刑或替代刑警。

## 范围、证据等级与限制

- 目标用户：专业刑警及公安办案 / 法制人员；场景是真实刑事案件，不是游戏。仅研究公开产品与项目，不读取或保存真实卷宗、个人刑事记录或案情细节。
- 检察产品只能作为“刑事卷宗分析的相邻竞品”；电子数据取证装备是“上下游互补工具”；不与公安侦查系统等同。
- **厂商声称**：官方产品页、官网客户案例能证明供应商公开提供某能力，不能自动证明客户独立认可、实际性能或验收。
- **政府 / 客户报道**：政府官网、公安署名案例、官方媒体客户采访。属于落地线索；仍与合同、验收报告、独立测试不同。署名案例转载渠道也明确标注。
- **采购 / 中标 / 合同**：分别证明采购需求、选定供应商、签约；不能合并写成“落地验收”。本轮未读取任何主样本的正式验收结论。
- **第三方转载 / 传闻**：只用于找源。没有一手正文的能力与性能不进入结论。采购转载里的金额后来由官方源核实，正文遮挡处不猜。
- 本轮按8个维度进行首轮搜索；首轮有空结果、跑偏到通用词条或找不到官方源的情况，补做7次纠偏搜索，共15次 `web_search`。后续通过官方链接、`web_extract`、HTTP正文及浏览器读取补证，不无限搜索。
- 未取得统一口径性能测试、许可价格或报价明细。因此不做“破案率 / 准确率 / 性价比”排名，也不把某项目总金额当通用产品单价。

### 1. “小美”智能警务助手 — 国投智能

- **组织 / 地区 / 用户**：国投智能信息科技股份有限公司官方产品；面向公共安全执法人员，覆盖办案但并非刑警独占。具体部署客户及地区本产品页未给出。
- **功能**：多模态问答、线索筛查、多源综合研判、知识库问答、不同警务平台联动。
- **重叠**：与“Agent作为已有系统入口”高度相关；本页没有完整卷宗编目、事件时间线、供述矛盾检测或人际关系图的明确说明，也未证明自主计划、多步工具执行审计或工具权限边界。
- **交付证据**：未见本产品的私有化 / 公有云 / SaaS / 许可方式明示。不能从同厂商Qiko智能本推定“小美”的交付形式。
- **落地判断**：**厂商声称，官方产品存在；本轮没有具名公安采购、客户投产公告或验收。** 初次搜索发现的公司ESG转载里有“多个地区部署”等自报内容，但未取得对应客户资料，不升级为已验证案例。
- **来源 / 日期 / 读取**：[官方产品页 S01](https://myai.sdic.com.cn/gtznn/kjcx/hxcp/ggaqdsj/rgzn/webinfo/2025/06/1751193342254949.htm)；页面日期2025-06-11，HTTP正文读取成功，`web_extract`曾超时。页脚CMS再生成时间不是初次发布日期。

## 对私有项目的定位建议（研究判断，不是厂商已验证功能）

### 建议验证的最小切口

1. **出处可回溯的卷宗结构化**：对经过授权的材料抽取人物、时间、地点、行为陈述和证据引用；每个字段保留页码 / 段落 / 原句 / 原文件标识，保留OCR错误与缺页的不确定性。
2. **“待核对”的矛盾清单，而非真假裁判**：并列原文、证据日期和主体；区分明确冲突、时间精度差异、记忆不一致、待确认实体，用户可标记误报。不要自动判定谁撒谎或有罪。
3. **事件时间线与关系图的人工可编辑性**：不要混同事件时间、材料制作时间、取证时间、办案流程时间。边和节点必须回溯出处；关系不等于参与犯罪。
4. **从只读Agent开始**：仅调用授权的本地文档检索 / 要素提取 / 核对工具。跨公安系统查询、下载、发送或修改必须另有接口授权、案件隔离、审批及审计，不能按厂商“自主闭环”话术默认放开。
5. **减少办案人员重复输入**：既有电子卷宗、笔录系统与权限是壁垒，不是一个聊天框可以替代的。先验证脱敏 / 合成测试材料上的可靠性和可复核性，再谈真实业务接入。
